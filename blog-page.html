Getting Started with Semantic HTML5

By Mariam Alshhar | November 26, 2026

When we start learning web design, it is easy to build every page using only <div> elements. The page may look fine in the browser, but the code does not tell anyone what each part of the page actually means.

Semantic HTML solves this problem. Semantic elements describe their content: a <header> is the top of a page, a <nav> holds the navigation links, and an <article> contains a complete piece of content that can stand on its own.

Why Semantic HTML Matters

Semantic code is easier to read and maintain. It also helps screen readers understand the structure of the page, which makes websites more accessible for people with visual impairments.

Search engines like Google also use these elements to understand which part of the page is the main content, which can improve how the page appears in search results.

The Most Common Semantic Elements

The most used elements are <header>, <nav>, <main>, <article>, <aside>, and <footer>. Elements such as <figure>, <time>, and <address> add even more meaning to small parts of the content.
